Como usar o Rádio

  • 1. LIGAR: Aperte o botão LIGAR à direita para iniciar a rádio selecionada. Clique novamente para desligar.
  • 2. SINTONIA: Clique no botão SINTONIA para abrir a lista com as rádios. E escolha uma rádio, ou use as setas « » para mudar de rádio. Depois de escolher, sempre clique em LIGAR para tocar a nova rádio.
  • 3. VOLUME / MUTAR: Aperte o botão VOLUME à esquerda para desligar ou ligar o volume.
